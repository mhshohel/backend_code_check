> Rerun of the Fastify variant alone, kept for transparency. During this run the

Generated by `scripts/bench/run-benchmarks.ts` on 2026-11-25T20:44:15.055Z.

- Hardware: Apple M3 Max, 16 logical cores, 64 GiB RAM, Node v26.13.0; PostgreSQL 17 (Homebrew, local); Elasticsearch 9.2.4 in Docker (1 GB heap).
- Dataset (ofl_bench, bench profile with BENCH_CUSTOMERS=40): 20060 products, 200039 orders, 800303 inventory movements, 42 customers.
- The bench data is reloaded before the worker run and before each variant, so every run starts from the same state.
- Load generator and server run on the same machine. Closed loop: each connection sends its next request after the previous response.
- Warm-up 3 s (not recorded) except for the hot-SKU run. Server started with raised rate limits (scripts/bench/serve.ts), NODE_ENV=production, DB_POOL_MAX=20.
- An error is an HTTP failure or a GraphQL `errors` entry. `InsufficientStock` is a correct business result, not an error.
